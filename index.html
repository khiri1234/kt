Using this on two PCs? For real-time sync, run the included server.js on one PC and open this page at its network address from both PCs (see README) — the badge above the Print button will show "🟢 Synced" when it's working. Without the server, the archive stays local to this device; use Export backup (.json) / Import backup (.json) to move data between PCs manually — imports merge rather than overwrite.
